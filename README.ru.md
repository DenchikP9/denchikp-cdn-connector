# Коннектор DenchikP CDN для Claude и ChatGPT

[English version](README.md)

Удалённый сервер [Model Context Protocol](https://modelcontextprotocol.io), который подключает ИИ-ассистентов к [DenchikP CDN](https://cdn.denchikp.com) — хранилищу файлов и сети доставки контента. Через него Claude, ChatGPT и другие клиенты MCP смотрят квоты, находят, читают и рассматривают файлы, загружают новые и создают ссылки для скачивания.

**Адрес сервера:** `https://cdnapi.denchikp.com/mcp`

В этом репозитории — открытая документация коннектора, список инструментов в машиночитаемом виде, пакет для каталога приложений ChatGPT и скрипты проверки работающего сервера. Сам сервер входит в API DenchikP CDN и здесь не публикуется.

## Что умеет коннектор

- Показывать тариф, квоты, использование и домены, на которые можно загружать
- Находить файлы по имени, папке или расширению; показывать ссылки, размеры и даты
- Читать текстовые файлы (html, css, js, json, md) и смотреть картинки (jpg, png, webp, gif)
- Загружать новые файлы из текста, base64 или по ссылке, а также до 20 текстовых файлов за раз
- Делать ссылки на картинки другого размера и формата (webp, avif) и временные подписанные ссылки
- Создавать ссылки для скачивания с паролем, сроком действия и лимитом скачиваний
- Показывать статистику, файлы со сроком жизни, корзину, дубликаты, контрольные суммы и проверку антивирусом

Коннектор **не может** удалять, перезаписывать, переименовывать и менять существующие файлы. У всех 22 инструментов `destructiveHint: false`. Все инструменты и параметры — в [docs/tools.md](docs/tools.md).

## Подключение

### Claude (claude.ai, приложения для компьютера и телефона)

1. Откройте **Настройки → Коннекторы** и найдите **DenchikP CDN** в каталоге. Если его там нет, выберите **Добавить свой коннектор** и укажите `https://cdnapi.denchikp.com/mcp`.
2. На странице согласия DenchikP CDN введите API ключ (или подтвердите ключ своей сессии панели) и нажмите **Разрешить**.
3. Включите коннектор в чате и спросите, например: «Сколько места осталось на моём CDN?»

### Claude Code

```sh
claude mcp add --transport http denchikp-cdn https://cdnapi.denchikp.com/mcp
```

Затем выполните `/mcp` и войдите в браузере.

### ChatGPT

Установите **DenchikP CDN** из каталога приложений ChatGPT. Пока его там нет, подключите в режиме разработчика: **Настройки → Приложения и коннекторы → Дополнительные настройки → Режим разработчика**, затем **Создать**, название `DenchikP CDN`, адрес `https://cdnapi.denchikp.com/mcp`, вход через **OAuth**.

### Другие клиенты MCP

Подойдёт любой клиент, который подключается к удалённым серверам по Streamable HTTP с OAuth 2.1 (PKCE S256 и динамическая регистрация клиентов). Адреса возврата loopback (`http://localhost:<порт>/...`, `http://127.0.0.1:<порт>/...`) принимаются на любом порту.

## Примеры запросов

- «Сколько места осталось на CDN и на какие домены я могу загружать?»
- «Выложи эту страницу (index.html, style.css и app.js) на мой домен и пришли ссылку.»
- «Что изображено на картинках в папке img домена example.com?»
- «Сделай ссылку на logo.png шириной 400 px в формате webp.»
- «Создай ссылку для скачивания report.pdf с паролем на 7 дней.»
- «Найди дубликаты файлов на моём домене.»

## Вход и права

- OAuth 2.1 с PKCE (S256), динамической регистрацией клиентов (RFC 7591), токенами обновления с ротацией, отзывом (RFC 7009) и `iss` в ответе авторизации (RFC 9207).
- API ключ вводится один раз на странице согласия и не сохраняется. Ассистент получает собственный токен только с правами `read`, `upload` и `share`.
- Токен доступа живёт 90 дней и продлевается автоматически, пока коннектор используется.
- Отозвать доступ можно в любой момент: удалите токен «Claude (MCP)» или «ChatGPT (MCP)» в панели DenchikP CDN.

Подробнее: [docs/authentication.md](docs/authentication.md).

## Данные и конфиденциальность

Коннектор получает только аргументы вызванных инструментов и возвращает их результат. Переписка, память ассистента и другие файлы ему недоступны. См. [политику конфиденциальности](https://cdn.denchikp.com/privacy/) (раздел 2.8) и [условия использования](https://cdn.denchikp.com/terms/).

## Проверка сервера

```sh
python scripts/check_server.py
```

Скрипт проверяет обнаружение OAuth, регистрацию клиента и ответ 401 у работающего сервера. Нужен только Python 3.9+, учётные данные не нужны. Та же проверка раз в неделю запускается в GitHub Actions.

## Пакет для каталога приложений ChatGPT

```sh
python scripts/build_chatgpt_plugin.py --check-only
python scripts/build_chatgpt_plugin.py --demo-url https://example.com/demo.mp4
```

Исходники пакета — в [chatgpt-plugin](chatgpt-plugin), архив создаётся в `dist/`. Порядок отправки — в [docs/directory-listing.md](docs/directory-listing.md).
