# Security

Please report vulnerabilities in the DenchikP CDN connector or its OAuth flow privately to **support@denchikp.com** with the subject "Security". Do not open a public issue.

Include the affected endpoint, the steps to reproduce and the impact. Never include real API keys or tokens: create a test key for the report.

We answer within a few days and publish a fix note in the [version history](https://cdn.denchikp.com/guide/?lang=en#changelog) once the issue is resolved.
